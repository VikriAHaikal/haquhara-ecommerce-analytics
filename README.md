# 💄 Haquhara - E-Commerce Sales, Customer Retention & Inventory Analytics

## 📌 Project Overview
Proyek analisis data e-commerce ini dirancang untuk mengevaluasi performa penjualan brand kecantikan (**Haquhara**) di berbagai saluran distribusi (Shopee, TikTok Shop, Official Website, Tokopedia). Fokus utama analisis meliputi kontribusi pendapatan per *channel*, keseimbangan porsi kategori produk (*Skincare vs Makeup*), tingkat retensi pelanggan (*repeat purchase rate*), serta pemantauan stok otomatis untuk optimasi inventaris.

---

## 🛠 Tools & Tech Stack
- **Data Analytics & Engine:** Python (Pandas, NumPy, SQLite3)
- **SQL Queries:** CTEs, Aggregations, Window Functions
- **Executive Dashboard:** Google Sheets (KPI Cards, Dynamic Charts, Automated Formulas)

---

## 📊 Key Insights & Business Recommendations
1. **Core Sales Channels:** Shopee (47.1%) dan TikTok Shop (32.8%) menjadi kontributor utama yang menyumbang **~80%** dari total omzet e-commerce.
2. **Balanced Category Contribution:** Kategori Skincare (50.5%) dan Makeup (49.5%) memiliki porsi kontribusi penjualan yang sangat seimbang.
3. **Customer Retention:** *Repeat Customer Rate* berada di angka **~33%**, menunjukkan tingkat loyalitas pelanggan yang sehat pada produk kosmetik & skincare.
